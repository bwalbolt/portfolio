A 2015 MacBook Air is not a benchmark champion, but it remains a useful way to test whether a development workflow is carrying unnecessary weight.

The best improvements were unglamorous: fewer background apps, a smaller browser tab count, and choosing tooling that leaves room for the editor and local server to breathe.

## Constraints make tradeoffs visible

Older hardware makes expensive dependencies obvious. It is a good prompt to profile before adding another layer to a project.
